# Reflection

Automation plays an important role in managing large numbers of cloud servers because handling everything manually becomes inefficient and difficult to maintain as systems grow. A task that takes only a short time on one server could require hours when repeated across multiple machines. By using scripts, administrators can perform the same operations consistently across different servers while reducing the chances of human error.

However, automation also introduces risks because mistakes can affect multiple systems at once. When an administrator makes an error during a manual operation, the damage may be limited to a single server. On the other hand, an incorrect command included in an automated script could be executed across hundreds or even thousands of machines. This could result in widespread system failures. One example is the 2012 Knight Capital incident, where a software deployment error caused the company to lose approximately $460 million within 45 minutes.

Working with Bash scripts reminded me of traditional procedural programming, where variables, conditions, and commands are executed in a specific sequence on a single machine. Docker Compose from Mission 6 works differently because it follows a declarative approach. Instead of specifying every action step by step, I describe the intended configuration of the application, including its containers, images, connections, and environment variables. Docker then handles the process of bringing that configuration into operation.

Reviewing my GitHub repository, which now covers Laboratory Activities 1 through 9, I can see how much my understanding of cloud computing has developed. What I initially viewed as simply using remote storage has expanded into a broader understanding of cloud engineering. I have gained experience with infrastructure provisioning, container deployment, data management, server security, system monitoring, and automated maintenance. Each laboratory introduced new concepts while building upon the knowledge and practical skills developed in the previous activities.
