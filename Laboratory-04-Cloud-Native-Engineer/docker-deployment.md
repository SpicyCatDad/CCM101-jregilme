# Docker Deployment Log

| Command | What It Does |
|---|---|
| `docker ps` | Lists all currently running containers. |
| `docker stop my-nginx` | Gracefully stops the running `my-nginx` container. |
| `docker ps -a` | Lists all containers (running and stopped) to confirm the container has stopped. |
| `docker rm my-nginx` | Permanently removes the stopped container from the host. |
