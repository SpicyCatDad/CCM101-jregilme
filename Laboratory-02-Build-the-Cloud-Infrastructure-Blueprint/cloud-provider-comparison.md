## Cloud Provider Comparison

| Infrastructure Component             | AWS                         | Microsoft Azure        | Google Cloud Platform |
| ------------------------------------ | --------------------------- | ---------------------- | --------------------- |
| Compute                              | EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Compute Engine        |
| Storage                              | S3 (Simple Storage Service) | Azure Blob Storage     | Cloud Storage         |
| Networking                           | Virtual Private Cloud (VPC) | Virtual Network (VNet) | VPC Network           |
| Identity and Access Management (IAM) | AWS IAM                     | Microsoft Entra ID     | Cloud IAM             |

## Guide Questions

**1. Which cloud provider offers the broadest range of services?**
AWS is generally viewed as having the widest selection of cloud services. It has a large catalog covering areas such as computing, storage, machine learning, IoT, analytics, and more.

**2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products?**
Microsoft Azure would be the best choice because it works closely with Microsoft 365, Active Directory, and Windows Server. This makes identity management and integration with existing Microsoft systems easier.

**3. Which platform is widely recognized for AI, ML, and Kubernetes services?**
Google Cloud Platform is well known for its AI and machine learning capabilities, as well as its Kubernetes services. Google was also heavily involved in the development of Kubernetes and offers tools such as Vertex AI.

**4. What similarities did you observe among the three cloud providers?**
All three providers offer essential cloud services such as compute, storage, networking, and IAM. They also use pay-as-you-go pricing, support container orchestration, and operate data centers across different regions to improve reliability and reduce latency.
