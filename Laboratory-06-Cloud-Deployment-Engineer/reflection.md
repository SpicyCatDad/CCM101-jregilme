# Reflection – Laboratory 6: The Cloud Deployment Engineer

In this laboratory activity, I learned how to use Docker Compose to deploy a two-tier cloud storage application consisting of Nextcloud and MariaDB in an Ubuntu environment through KillerCoda. I learned that instead of creating and managing containers individually, Docker Compose allows multiple containers to be configured and deployed together using a single YAML configuration file.

I also gained experience creating the `docker-compose.yml` file using the nano text editor, verifying its contents, and using commands such as `docker-compose up -d`, `docker-compose ps`, and `docker-compose down` to deploy, monitor, and remove the application stack. This helped me understand how Infrastructure as Code makes deployment more consistent, organized, and efficient.

Overall, this laboratory improved my practical knowledge of Docker Compose and multi-container deployment. It showed me how the Nextcloud application and MariaDB database work together as separate services. I realized that Docker Compose is a useful tool for simplifying application deployment and managing cloud infrastructure, which will be valuable in my future work as an IT student.
