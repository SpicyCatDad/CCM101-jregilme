## Disk Storage

\- Total storage capacity of the root (`/`) file system: 19 GB

## Why Disk Space Matters Before a Traffic Surge

Checking disk space before a traffic surge is critical because logs, cached files, and temporary data can grow rapidly under heavy load. If the disk fills up, the server may be unable to write logs or serve requests, turning a performance problem into a complete outage.
