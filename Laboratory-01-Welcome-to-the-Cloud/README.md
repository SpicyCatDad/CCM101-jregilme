# Laboratory Activity 1: Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to the role of a Junior Cloud Infrastructure Engineer Trainee at CloudNova Technologies. The activity focused on getting familiar with a cloud-based Linux environment and performing basic Linux administration tasks.

## Objectives

* Set up and access a Linux environment through KillerCoda
* Learn how to navigate and work with the Linux operating system
* Check and record basic system information
* Create and organize directories and files
* Set up a GitHub repository for my cloud computing portfolio
* Practice documenting activities using Markdown

## Activities Performed

1. Started an Ubuntu environment through KillerCoda
2. Added a new user with sudo privileges and logged into the account
3. Collected information about the Linux distribution, kernel, CPU, memory, and storage
4. Created an organized folder structure for Documents, Notes, Reports, and Screenshots
5. Created and edited Markdown files for laboratory documentation
6. Created and prepared a GitHub repository for the portfolio

## Linux Commands Used

* `adduser`, `usermod`, `su`
* `whoami`, `pwd`, `hostname`
* `cat /etc/os-release`, `uname -r`, `lscpu`, `free -h`, `df -h`
* `mkdir`, `ls`, `nano`, `touch`, `cat`

## Skills Learned

This activity helped me develop basic Linux navigation and command-line skills. I also learned how to manage users and permissions, organize files and directories, create Markdown documentation, and use Git and GitHub for managing and presenting my work.
